* Sources & méthodologie

Le filtre « Source / Canal » s'appuie sur la colonne Source d'origine de HubSpot.
  • Référencement payant → Google Ads · Campagne sociale payante → Meta Ads · Recherche naturelle → SEO. Données réelles HubSpot.
  • Trafic direct · Sources hors ligne · Autres campagnes · Renvois · Réseau social organique · Renvois IA — libellés HubSpot repris tels quels. Données réelles.

Funnel : contacts entrés dans chaque étape sur la période. Vue Mensuelle = 13 mois glissants (MoM) · Vue Hebdo = 14 semaines glissantes (WoW). « Tous les canaux » = somme des sources. La dernière période est partielle.

Le coût par résultat est coloré par tiers sur les lignes affichées (vert = les plus faibles, rouge = les plus élevés). Cliquez sur les en-têtes de colonnes pour trier (croissant / décroissant).
